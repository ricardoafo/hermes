# Documentation

Start with the [README](../README.md) for what Hermes is and how to run it. This page
lists where everything else lives.

| Folder | What it holds | Start here |
| ------ | ------------- | ---------- |
| [`architecture/`](architecture/README.md) | Architecture decision records (ADRs): what Hermes is built from and why. Accepted ADRs don't change; a new ADR supersedes an old one. | [ADR-003](architecture/adr-003-solution-architecture/), the solution architecture |
| [`guides/`](guides/README.md) | How-to guides: local setup, development workflow, tests, releases, operations. | [Local setup](guides/local-setup.md) |
| [`decisions/`](decisions/README.md) | Smaller choices, dated, that don't need an ADR. | The newest file |
| [`design/`](design/README.md) | Console design: layout, screens and the visual system. | [Console cockpit](design/console-cockpit.md) |
| [`experiments/`](experiments/README.md) | Signed pre-registrations, trial logs and research records. Kept byte-for-byte as signed. | [Swing MVP1 pre-registration](experiments/swing-mvp1/pre-registration-v1.md) |
| [`research/`](research/README.md) | Notes on the outside material behind decisions. | [Feasibility study](research/2026-08-feasibility.md) |
| [`runbook/`](runbook/README.md) | Step-by-step procedures for operating the deployed engine. | [Secret rotation](runbook/secret-rotation.md) |

Issue and pull request numbers in these documents (for example `#1353`) refer to
this repository's tracker.
