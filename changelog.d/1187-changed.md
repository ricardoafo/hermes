- **One Telegram HTTP transport** (`hermes.adapters._shared.telegram_http`): the urgent-alert notifier and `hermes bot` now share one Bot API call that builds the method URL, waits out an HTTP 429 (at most 3 retries within a 30 s whole-call budget) and checks the reply, so `hermes bot` now retries a 429 instead of failing the reply; the Slack and Telegram notifiers share one correlation-tail helper; `TelegramBotError`, `JournalUnavailableError` and `ScenarioError` are now `InfraError`s (still `RuntimeError` / `ValueError`).
