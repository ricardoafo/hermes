- **A release is cut at every merge window** (ADR-028, `scripts/dev/cut-release.py --next`): after a window's merges land, a release PR covering every changelog entry since the last cut goes last on that window's list, so the version moves with each batch. `--next --engine-change yes|no` picks the version: a PATCH when every entry is a fix or security fix and the engine line is `no`, a MINOR otherwise; it refuses a cut with no entries.
