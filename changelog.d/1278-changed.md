- **Every merge deploys with a computed version** (`.github/workflows/cd.yml`, `scripts/deploy/next_version.py`): each push to `main` that changes a file the release bundle carries now deploys to hermes-01 as the next version, MINOR for a feature, breaking change or engine file and PATCH otherwise, computed from the changelog fragments since the last `v` tag. Docs, tests and CI pushes deploy nothing. The version is settled under the deploy lock, the release PR and the `DEPLOY_ON` variable are retired, and `scripts/deploy/version_release.py` is removed (ADR-030).
